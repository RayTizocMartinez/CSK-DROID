Prompts Builder

When you open the phone by double-clicking index.html, the browser won't let it read your .txt prompt files. This page packs them into js/prompts-data.js so the Writer's texts work anyway. Nothing is uploaded anywhere.

Only needed for double-click testing. On GitHub Pages or Live Server the phone reads the .txt files directly.

  1. Click the green button and choose your media/prompts folder (or select the .txt files).
  2. Click Download prompts-data.js and put it in the js folder, replacing the old one.
  3. Do this again whenever you edit the text files.
