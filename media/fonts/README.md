# fonts/

Android 2.1 used **Droid Sans**. Dropping it here makes every screen look much more authentic. Without it, the phone falls back to Roboto / Segoe UI / Arial.

**Files (exact names):**

- `DroidSans.ttf`
- `DroidSans-Bold.ttf`

Droid Sans was released by Google under the Apache 2.0 license, so it's free to include. Search for "Droid Sans ttf" (Google's old fonts repo, or Font Squirrel) and rename the files to match the names above if needed.
