# icons/

Replacement home screen / app drawer icons. Leave this empty to use the built-in Eclair-style icons.

**File names: `<app id>.png`**

| App | File |
|---|---|
| Phone | `phone.png` |
| Messaging | `messages.png` |
| Gallery | `gallery.png` |
| Contacts | `contacts.png` |
| Settings | `settings.png` |
| Pod Stack | `podstack.png` |
| Flappy Nick | `flappynick.png` |
| Match Killer | `match3.png` |
| Flyer Maker | `flyer.png` |
| Nick's Pee | `jar.png` |
| Maps | `maps.png` |
| Killmiibos | `characters.png` |
| Nick Run | `nickrun.png` |
| Line Ryder | `sled.png` |
| Balloon Heist | `balloons.png` |
| Mask Stack | `topple.png` |
| ClikCok | `clikcok.png` |

New apps (games, etc.) will follow the same pattern: their id + `.png`.

**Size:** 96 × 96 px PNG **with a transparent background**. Eclair icons were free-form objects (a handset, a speech bubble, a picture frame) rather than squares, often with a soft drop shadow and a slight top-down tilt.
