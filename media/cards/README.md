# cards/  —  CSK TCG card art

One square image per card, named after the card's id. The game draws the frame, cost, stats, name and text around it, so just make the picture.

**Size:** 512 × 512 PNG, subject in the middle (the battle board crops it to a rounded token). Missing art draws a placeholder with the card's initials.
