# app-icon/

The icon for the installed app (Add to Home Screen) and the browser tab.

**Files (replace the placeholders, keep these exact names):**

- `icon-192.png`: 192 × 192 px
- `icon-512.png`: 512 × 512 px

**Tips**

- Square PNG, no transparency needed.
- Android crops the 512 icon into a circle or rounded square, so keep the important part inside the middle ~70%.
- To change the installed app's *name*, edit `name` and `short_name` in `manifest.json` in the main folder.
